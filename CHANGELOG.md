# Changelog

## 0.1.0-rc.4 · 2026-10-07

First official public source home for the existing RC4 evaluation clients.

- Python/JavaScript runtime and types preserved from public packages.
- Account-free recovery example through both installed clients.
- Shared HTTP failure matrix and exact-original recovery checks.
- Deterministic offline packages, source bundle, manifest and checksums.
- Recovery, compatibility, security and release-scope documentation.

No kernel upgrade or production qualification is claimed.
